# Research protocol

## Primary research question

For a defined animal species, genome build, edit class, and intended outcome, can the system reliably prioritize observed unintended consequences and welfare-relevant outcomes from evidence available before outcome evaluation?

## Unit of analysis

- Animal species, strain/breed, genome build, and functional-annotation version must be recorded for every run.
- Intended outcome, welfare endpoints, evidence sources, and outcome window are pre-registered.
- Data quality control and provenance verification precede model assessment.

## Modelling sequence

1. Establish a transparent baseline from evidence availability and annotation context.
2. Combine only versioned, pre-declared evidence on on-target uncertainty, candidate off-target effects, network context, and welfare relevance.
3. Use held-out historical outcomes for evaluation and an independent laboratory or dataset for final replication.
4. Report calibration, false-negative/false-positive trade-offs, and performance by species, strain/breed, genome build, and edit class.
5. Publish concern tiers, evidence traces, uncertainty, applicability limits, and negative results.

## Minimum acceptance criteria

A model is not promoted beyond exploratory status without independent replication, calibrated uncertainty, sensitivity analysis, documented species/strain/edit-class performance, and an animal-welfare review pathway.
