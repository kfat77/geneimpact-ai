# Model card template

## Intended use

Research prioritization of gene and gene-pair hypotheses for a named phenotype. Not intended for diagnosis, prognosis, treatment selection, or consumer health reporting.

## Required release fields

- phenotype and operational definition
- cohorts, sample sizes, recruitment setting, and inclusion criteria
- genome build, annotation release, and variant QC
- model form, feature definitions, interaction search space, and hyperparameters
- effect size, uncertainty interval, calibration, and external replication result
- subgroup performance and known limitations
- data provenance and code/model version identifiers
