# Model card template

## Intended use

Research prioritization of plausible consequences of a proposed animal genome edit. Not intended as an authorization, a welfare determination, or a substitute for animal-ethics, biosafety, veterinary, or regulatory review.

## Required release fields

- species, strain/breed, genome build, and edit class
- intended edit outcome and welfare-relevant endpoints
- source versions for reference genome, functional annotation, and outcome evidence
- model form, evidence features, uncertainty strategy, and thresholds
- concern-prioritization performance, calibration, and independent replication result
- performance by species, strain/breed, genome build, and edit class
- known limitations, evidence gaps, and animal-welfare review requirements
- data provenance and code/model version identifiers
